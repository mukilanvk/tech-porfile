# Mukil — React Developer Portfolio

Responsive single-page portfolio built with React, TypeScript, and Vite.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Content to personalize

This workspace was empty when the portfolio was started. The page uses the facts and project descriptions from the supplied brief and reference. Add the actual resume PDF, public contact email, LinkedIn/GitHub URLs, and real project screenshots when available. Project cards currently use clearly labeled illustrative previews rather than product screenshots. See `public/assets/asset-manifest.md` for the generated and code-built visual inventory.
